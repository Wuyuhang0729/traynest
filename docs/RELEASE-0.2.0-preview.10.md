# TrayNest 0.2.0-preview.10

## 新增

- 右键入口 → 面板外观，可选亚克力、浅色、深色或跟随系统托盘。选择会保存；旧配置默认跟随系统托盘的浅深色模式。
- 亚克力使用更轻的背景染色，保留模糊与颗粒感，图标保持不透明。关闭 Windows 透明效果或启用高对比度时使用实色回退。

## 修复

- 修复待机唤醒后托盘短暂无响应时，重新隐藏图标触发程序主动退出的问题；现在保留进程并等待托盘恢复。
- 拖动图标到入口自动展开时，暂停同步访问 Explorer 界面树，避免拖动双方互相等待；拖动期间使用缓存或原生窗口边界定位。
- 面板在系统隐藏区左侧展开时底部对齐，上方展开时左侧对齐；面板及其收起动画保持在任务栏下层。

## 安装与升级

下载完整 Windows x64 ZIP，解压后运行 Install.cmd；也可直接运行 NestedTray.exe 便携使用。完整包自带 .NET 10 运行时。

升级前先正常退出旧版。用户收纳布局、工具启动文件和外观选择保存在独立目录，安装不覆盖这些设置。若改变程序安装位置，请在新位置重新启用开机启动，使登录任务指向新程序。

## 验证与边界

已完成针对性检查：外观切换与保存、失败回滚、实际自有图标拖到入口、面板位置与层级、展开收起动画，以及托盘通信超时和恢复。亚克力在 Windows 11 25H2 实际预览核对。

八小时中断恢复检查使用模拟时钟，不能代替真实整夜待机复测。其他 Windows 构建、多屏、混合 DPI 和全部第三方软件仍需扩大实机覆盖。

可调染色采用 Windows accent policy 的兼容接口，不属于稳定的公开 API 合约；不可用时回退到系统亚克力。不同 Windows 版本和系统设置可能呈现不同的透明效果。

原生拖动可能出现禁止标志、部分图标缺少登记信息等既有兼容限制仍保留。

另有用户反馈：系统隐藏区内拖动后，原位置可能残留浅色图标。该问题尚未定位，暂不视为已修复。
