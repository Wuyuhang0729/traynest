# TrayNest 全部功能

对应当前公开版 **0.2.0-preview.17**。仅列当前已提供能力；具体操作见[使用指南](USER_GUIDE.md)。

## 图标收纳与布局

- 从系统隐藏区拖入收纳。
- 面板内拖动排序，拖出移回。
- 松手保存，Esc 取消排序。
- 悬停、拖入落点和排序反馈。
- 保存收纳项目、顺序与启动目标。
- 每行设置 5–8 个图标，内容较多时滚动。
- 原软件未启动时保留淡色占位。
- 图标重新登记后，匹配原收纳位置。
- 确认后全部移回，清空收纳列表、顺序和启动目标。

## 原软件交互与启动

- 转交原软件的单击、双击和右键菜单。
- 点击离线占位，尝试启动原软件。
- 右键指定 EXE 或快捷方式。
- 对已识别的商店应用使用 Windows 应用标识激活。
- 显示启动中、超时或失败等状态。

来源登记、权限和启动目标会影响可用性，不保证所有图标都可收纳或启动。

## 面板模式

- **联动模式（默认）**：TrayNest 使用蓝色嵌套方框入口，配合系统隐藏区。
- **独立模式**：新增 TrayNest 自己的蓝箭头入口；系统原有的 `^` 保留，两个入口各开自己的面板。
- 蓝箭头随收纳面板开收转向。
- 两模式共用收纳项目、顺序和外观。
- 两模式分别记住入口位置偏好；实际位置由 Windows 管理，可手动拖动调整。
- 联动面板可选系统隐藏区左侧或上方，边缘对齐。
- 独立面板固定在自身蓝箭头上方居中。
- 面板位置避让屏幕工作区边界。

## 打开与关闭

- 点击 TrayNest 托盘入口开收。
- **手动打开（默认）**：点击入口或使用快捷键。
- **跟随系统面板**：仅联动模式可选。
- **悬停入口**：停留约半秒后展开。
- 拖动图标靠近入口时展开，方便收纳。
- 跟随模式可选同时展开，或系统面板先展开。
- 展开与收起动画，快速反向衔接。
- 默认全局快捷键 **Alt+D**，可更改或清除。
- 快捷键占用或保存失败时保留原设置。
- 联动快捷键默认控制两面板，可改为仅收纳；独立仅控制收纳。
- 系统完整空白格双击开收：**仅联动，默认关闭**。
- 排除图标、边框、单击与拖动；可重看双击图示说明。

系统隐藏区只有一行时会随内容收缩；空白格双击需要实际存在完整空格，例如多行布局末行的空位。

## 外观与主题

- 设置窗口：浅色、深色、跟随系统三种主题。
- 收纳面板：跟随系统、亚克力、浅色、深色四种外观。
- 窗口主题与面板外观独立设置。
- 可同步系统隐藏区的背景样式。
- 关闭同步或正常退出后恢复系统原背景。
- 透明效果受 Windows 设置与任务栏环境影响。

## 设置与辅助

- 四类设置：常规、打开方式、外观与布局、关于与反馈。
- 设置页在本机加载。
- 开机启动：登录 Windows 后运行 TrayNest，**默认关闭**。
- 从设置打开收纳面板或刷新图标。
- 从设置查看版本、打开项目主页。
- 复制或导出脱敏诊断报告。
- 错误编号、事件 ID 与限量日志，便于反馈。

## 检查与下载更新

- 手动检查更新。
- 自动检查：**默认开启，每天最多一次**。
- 重要更新提醒：**独立开关，默认开启**。
- 仅对项目明确标记的重要版本提醒。
- 关闭自动检查后，仍可手动查询。
- 展示版本说明和下载状态。
- 用户触发下载，核对安装器来源、版本、大小和 SHA256。
- 校验完成后，由用户确认退出并更新。
- 网络、超时或限流失败不当作“没有更新”。

## 安装、退出与恢复

- 当前用户 Inno Setup 安装向导。
- 独立 EXE 安装器、完整 ZIP 和便携运行。
- 自带 .NET 10 运行时。
- 检测 WebView2；缺少时提供微软手动下载入口。
- 下载资产附 SHA256，完整载荷附逐文件清单。
- 覆盖安装保留配置、布局和原自启动。
- 正常退出后更新，保留旧版备份与启动确认保护。
- 安装失败恢复保护；无法确认时保留记录并提示。
- 正常退出恢复原图标和系统背景，保留收纳布局。
- 安装版提供卸载入口，**默认保留配置**；清除数据需再次确认。

## 使用范围

目标为 Windows 11 x64，当前实机依据为 Windows 11 25H2。灰暗/叹号及双面板状态差异等问题仍待排查；RetroBar 暂不支持共存，StartAllBack 未完成实测。其他 Windows/DPI、登录睡眠及完整第三方矩阵未全部覆盖。
