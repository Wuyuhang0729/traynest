# 0.2.0-preview.12

系统隐藏区与 TrayNest 收纳面板现在可以使用对应的材质。在“设置 → 面板”开启“统一两个面板的材质”，再选择亚克力、浅色或深色。跟随系统时，两个面板采用随系统明暗变化的亚克力。

关闭同步或退出 TrayNest 后恢复系统原背景。该功能自带原生桥接，无需安装 Windhawk；启用时会连接 Explorer 的隐藏区背景控件，不改变图标输入处理。连接失败会提示并保留原设置。

自动展开改为三选一：手动展开、跟随系统隐藏区、悬停入口。两种自动模式互斥，旧配置若同时开启则保留跟随系统隐藏区。拖动图标靠近入口时仍会自动展开。

本版还包含 preview.11 的独立设置窗口、仅保留“设置”的入口右键菜单、展开与重排后的对齐校准，以及 InputTip 进程路径读取失败造成的淡色重复占位修复。

README 与宣传页已按新版重做，移除三种人群案例，新增收纳前后对比、位置记忆、互斥展开和双面板材质说明。宣传图继续保留背景、界面与文字等可编辑图层。

验证范围：十组隔离回归；真实桌面的自动展开、入口拖动、菜单与材质设置交互；自有 XAML 宿主的原背景精确恢复和控制进程异常退出恢复；本机 Windows 11 25H2 的真实原生材质截图。详细桌面截图与私有配置不随公开源码分发。

主面板背景依赖 Windows 内部 XAML 控件，系统更新或任务栏美化工具可能影响兼容性。两个面板使用不同绘制技术，亚克力透光细节可能略有差别。尚未验证全部系统、显示配置和第三方软件。
