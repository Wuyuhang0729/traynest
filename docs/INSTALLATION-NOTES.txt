TrayNest · 安装前说明

当前支持目标为 Windows 11 x64。完整包自带 .NET 运行时；设置窗口还需要 Microsoft Edge WebView2 Runtime。未检测到时，安装向导提供微软官方下载入口，由你决定安装。

安装在当前 Windows 账户下。更新保留收纳配置、布局和现有自启动设置；首次安装的开机启动默认关闭。更新前请正常退出 TrayNest，让收纳图标和系统背景恢复。

当前已测 RetroBar 1.22.122 接管通知区时，TrayNest 不支持同时收纳。其他美化工具仅对记录的版本和组合保留实测结论；StartAllBack 尚未启用实测。完整边界见安装目录 docs/COMPATIBILITY.md。

安装前会备份原程序；失败恢复会明确说明结果。卸载默认保留配置，清除数据需要再次确认。完整许可证及第三方声明随程序保留。
