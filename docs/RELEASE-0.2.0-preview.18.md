# TrayNest v0.2.0-preview.18 · TN-027 阶段性修复

<!-- traynest-update:{"schema":1,"importance":"normal"} -->

本次更新优化了启动稳定性和异常恢复体验：

- 修复启动异常后，再次打开程序无响应的问题。
- 修复部分情况下程序运行中意外退出的问题。
- 改善托盘入口创建失败时的自动重试与恢复提示。

部分环境下的偶发启动及全屏兼容性问题仍在持续排查。

## 修复范围

- 再次打开可唤起同一路径的现有面板或启动错误窗口；启动错误窗口提供重试操作，无响应时给出明确提示。
- 修复图标正常删除与状态维护交错时，旧记录可能触发 TN2002 并停止收纳的问题。其他明确失败仍保留图标恢复保护。
- 入口注册与交互版本协商采用有界重试，部分登记失败会清理后再试。

## 诊断改善

增加入口注册步骤、调用耗时和状态维护消息路径的判别记录，帮助区分超时、明确拒绝、目标变化及正常删除。诊断改善不代表所有异常均已修复。

## 仍待验证与反馈

本次是普通预览更新，标记为 normal，不触发重要更新提醒；不代表 TN-027 或相关 Issue 全部解决。偶发入口注册拒绝的底层原因、报告者特定软件与显示配置下的全屏异常仍需反馈。本机自有全屏夹具验证不能替代报告环境。

更新前正常退出旧版，运行新版安装器覆盖安装，保留配置与排序。请核对版本为 preview.18，检查再次打开、原图标点击/菜单和排序；在日常使用或自然登录后观察入口与收纳是否正常。无需反复重启或强制结束进程。

若复发，请尽量保留现场，导出诊断报告，在对应问题下补充触发步骤、软件名称和显示配置：

- [启动/全屏后失效、进程仍在：Issue #4](https://github.com/Wuyuhang0729/traynest/issues/4)
- [启动后运行数分钟意外退出：Issue #5](https://github.com/Wuyuhang0729/traynest/issues/5)
