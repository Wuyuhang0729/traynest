# 固定工具区

将图标拖入 TrayNest 后，可在面板内拖动排列。顺序、名称、图标快照与每行列数保存在当前用户的本地配置中。正常退出、工具图标重新登记和下次启动都使用这套布局。新增图标追加，不随数量自动增加列数；需要改变列数时，可在入口右键菜单选择 5–8 列。

入口右键菜单“弹出位置”提供“左侧／上方”，选择后立即调整已显示的面板并保存偏好。系统隐藏区展开且包含入口时，以系统隐藏区为参照；否则以入口为参照。默认左侧，屏幕边缘空间不足时使用可容纳的另一方向，并保持在工作区内。正常退出后再次启动会沿用选择。

没有自启动、已经退出或暂时没有托盘图标的工具仍占原来的格子，图标以约 40% 透明度显示。其他图标不会自动补位。单击可尝试启动；连点启动期间不会重复启动。同一路径的程序已运行却还没有图标时，会提示等待，避免盲目再开一份。

等待图标时，格位显示“…”；启动目标无效、启动失败或等待超时显示“!”，悬停和可访问描述可查看具体原因。等待窗口为12秒，期间重复点击不会重复启动。到期提示“仍未发现图标，可右键检查启动文件”，不会自动重试，也不表示软件一定未运行。关闭重开面板仍可查看当前状态，图标登记后恢复正常。

内部排序拖动越过面板边界时会提示“松开移出收纳，Esc取消”；拖回可继续排序，Esc或丢失鼠标捕获会取消本次拖动。普通鼠标离开不触发移出。

入口菜单“移回全部并清空收纳…”默认取消；确认后，成功项释放，失败项保留可重试，离线条目仅在配置保存成功后删除。恢复记录无法安全更新时停止后续清空。结果分别列出已移回图标、已清除离线条目和失败项。正常退出仍保留收纳布局。

右键淡色图标可“尝试启动”“设置启动文件…”或“移出收纳”。启动支持有效的普通 EXE 或 Windows 快捷方式；需要参数或特殊启动方式的软件，建议选择其现有快捷方式。商店应用、权限受限、路径变化等情况可能无法启动，此时会显示提示，不会删除保留的格位。

图标重新登记并能匹配保存的身份后，在原位恢复正常交互。不能确定对应关系时，不会把其他软件的图标错误合并进原格位。软件升级导致路径、GUID 或图标 ID 改变，可能需要重新收纳。

开机自启动仅自动打开 TrayNest、恢复布局和规则。没有运行的工具不会被批量自动启动。尚未实际重启电脑验证所有登录顺序和第三方软件；已通过保存/加载、乱序到达、工具真实退出重开及自身重建的相关回归后再以测试报告为准。

“移出收纳”是用户明确释放条目；工具自己退出不会释放。正常退出 TrayNest 仍恢复正在运行的原生图标，保存的布局保留。

升级前版本只保存了收纳列表，没有保存拖拽后的视觉顺序。首次升级按已有列表建立布局；图标图像会在首次发现真实图标时补充缓存。旧版未保存的视觉顺序无法追溯，新版重新排列后会持久保存。

配置包含本机路径、工具名称和图标快照，只保存在本机；导出的诊断报告继续过滤这些内容，软件不会自动上传配置。
