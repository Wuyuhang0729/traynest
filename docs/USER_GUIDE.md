# 安装与使用

本文对应当前公开的 **0.2.0-preview.17**。[下载预览版](https://github.com/Wuyuhang0729/traynest/releases/tag/v0.2.0-preview.17) · [更新日志](../CHANGELOG.md)

## 安装与首次打开

需要 Windows 11 x64 和 Microsoft Edge WebView2 Runtime。完整包自带 .NET 10，不用另外安装 .NET；缺少 WebView2 时，向导提供微软下载入口，由你手动安装后重试。

1. 运行独立安装器 `TrayNest-Setup-v0.2.0-preview.17-win-x64.exe`；或完整解压 ZIP，运行外层 `TrayNest.Setup.exe` / 内层 `TrayNest/Install.cmd`。
2. 默认安装到当前用户的 `%LOCALAPPDATA%\Programs\TrayNest`，可选择创建桌面快捷方式；开机启动默认关闭。
3. 启动后打开系统隐藏图标区，点击 TrayNest 蓝色嵌套方框入口。默认联动模式、手动打开，也可按 Alt+D。
4. 将想收纳的图标拖进面板，右键 TrayNest 入口打开设置。入口可手动拖到任务栏常显位置，实际位置由 Windows 管理。

便携使用运行解压目录中的 `TrayNest/NestedTray.exe`。保留完整目录，包括运行时、`native/` 材质组件及许可证；目录内 `Create-DesktopShortcut.ps1` 可单独创建快捷方式。Release 为安装器和 ZIP 分别提供同名 `.sha256` 文件。

## 收纳、排序与启动

从系统隐藏区拖入收纳，在面板内拖动排序，拖出面板移回。松手保存，Esc 取消排序。图标继续转交原软件处理单击、双击和右键菜单；来源兼容性仍有差异。

TrayNest 保存收纳项目与顺序。原软件未启动时保留淡色占位，点击可尝试打开，右键可指定 EXE 或快捷方式。启动结果取决于原软件和目标设置；保存占位不代表来源必定在线或可启动。

## 设置 → 打开方式

- **面板模式**：默认联动；独立模式新增TrayNest自己的蓝箭头入口，系统原有的 ^ 保留；两个入口各开自己的面板，收纳面板固定在蓝箭头上方居中并避让屏幕边界。两模式共用收纳项目，分别记住入口位置偏好，不持续强制常显。
- **自动展开**：联动可选手动打开、跟随系统面板、悬停托盘入口；独立仅有手动与悬停。手动时点击入口或快捷键打开，拖动图标到入口也会展开。
- **展开顺序**：仅联动且跟随系统面板时显示，同时展开或系统面板先展开；切换模式后原偏好保留。
- **全局快捷键**：默认 Alt+D，支持更改或清除，点击“保存”生效；占用或保存失败保留原值。
- **快捷键仅控制收纳面板**：仅联动显示，默认关闭，即默认开收两个面板；独立始终只控制收纳。
- **双击空白处打开面板**：仅联动，默认关闭。在系统隐藏区完整空白格双击开收，再双击关闭；单击、图标、边框和拖动不触发。选项下可重看“查看使用说明”；没有空白格时用入口或快捷键。

## 设置 → 常规

- **开机启动**：默认关闭；开启后登录 Windows 运行 TrayNest，不负责启动所收纳的其他软件。
- **自动检查更新、重要更新提醒**：独立开关，默认开启；每天最多自动检查一次，只对项目明确标记的重要版本提醒。
- **检查更新 → 立即检查**：关闭自动检查后仍可手动查询。先由你点击下载，校验后再点击退出并更新；不会无人确认自动替换程序。
- **打开收纳面板、刷新图标**：分别打开面板、更新正在运行的图标显示。

## 设置 → 外观与布局

- **展开位置**：联动可选左侧底部对齐、上方左侧对齐；独立固定在自身入口上方，位置控件不可更改。
- **每行图标数**：5–8 个。
- **收纳面板外观**：跟随系统、亚克力、浅色、深色。
- **同步系统面板背景**：让系统隐藏区采用对应外观，关闭或正常退出后恢复原背景。透明效果受 Windows 设置与任务栏环境影响。
- **移出全部图标 → 全部移出**：确认后恢复图标，清空收纳列表、顺序与启动文件设置，不启动离线软件；未完成条目在失败时保留并提示。

设置窗口右上角可选择浅色模式、深色模式或跟随系统，与收纳面板外观独立。设置可见时其他入口仍按所选方式工作。

## 退出、更新与卸载

在设置左下方点击 **退出 TrayNest**，恢复原图标与系统背景，保留布局。手动安装新版前先正常退出旧版；覆盖安装保留配置、布局与原自启动，旧程序备份及失败恢复信息保留在维护记录指定位置。

安装版通过 **设置 → 关于与反馈 → 卸载 TrayNest** 打开向导。卸载默认保留配置，清除数据需再次确认；便携目录没有安装卸载入口，正常退出后再处理文件，配置默认保留。

## 兼容性与反馈

当前实机依据为 Windows 11 25H2 x64；其他 Windows/DPI、真实登录睡眠及完整第三方矩阵未全部覆盖。部分图标无法收纳或出现拖动禁止标志，灰暗/叹号及双面板状态差异仍待排查。RetroBar 暂不支持共存，StartAllBack 未完成实测；详见[兼容性说明](COMPATIBILITY.md)。

在 **设置 → 关于与反馈 → 诊断与反馈** 复制或导出报告，检查后主动提交。附版本、复现步骤、错误编号和事件 ID；报告会过滤用户名、完整路径、图标提示和窗口标题。

日志位于 `%LOCALAPPDATA%\NestedTray\logs`，程序限制其大小。[错误说明](ERROR_CODES.md) · [提交问题](https://github.com/Wuyuhang0729/traynest/issues/new?template=bug_report.yml)
