# 安装与使用

需要 Windows 11 x64 和 Microsoft Edge WebView2 Runtime；缺少时按微软入口手动安装。完整包自带 .NET 10 运行时，不用另外安装 .NET。

1. 下载独立 EXE 安装器；或完整解压 ZIP，运行外层 TrayNest.Setup.exe / 内层 TrayNest/Install.cmd。
2. 安装后从桌面快捷方式启动。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\TrayNest`，不会自动开启开机启动。
3. 点开系统隐藏图标区，找到蓝色嵌套方框入口，打开 TrayNest。
4. 把想收纳的图标拖进面板。右键入口打开设置。

便携使用可直接运行解压目录中的 TrayNest/NestedTray.exe。保留整个文件夹，尤其是 native/ 材质组件；Create-DesktopShortcut.ps1 可单独创建快捷方式。

在设置“常规”立即检查更新。自动检查与重要提醒分别控制，下载校验后由你点击退出并更新。手动安装先正常退出旧版；配置、布局及原自启动保留，失败恢复旧程序，备份位于维护记录指定位置。卸载默认保留配置，清除数据需再次确认。

## 收纳、排序与启动

从系统隐藏区拖入收纳，在面板内拖动排序，拖出面板即可移回。松手保存，Esc 取消排序。图标继续支持原软件的单击、双击和右键菜单。

TrayNest 会保存收纳项目和顺序。原软件未启动时，原位置保留淡色图标；点击可尝试打开，右键可指定 EXE 或快捷方式。启动结果取决于原软件和启动文件设置。

## 打开方式与快捷入口

默认联动模式；独立模式从蓝箭头开收，位于入口上方居中。两模式共用收纳项目，分别记住入口位置偏好，Windows 决定实际位置，可手动拖动调整。

默认 Alt+D，可修改或清除，须显式保存；冲突或保存失败保留原值。联动默认开收两面板，可选只开收纳；独立只控制收纳。

联动可开启系统完整空白格双击，默认关闭。双击切换开收，单击不动作，图标/边框/拖动不触发；选项下可重看图示。

设置窗口支持浅色、深色及跟随系统主题，与面板材质独立。设置可见时其他入口仍可用。独立模式仅显示有效的手动/悬停选项，联动偏好保留。

## 常规设置

右键入口只保留“设置”，打开的是独立窗口。

- 展开方式三选一：手动展开、跟随系统隐藏区、悬停入口。两种自动模式互斥。拖动图标靠近入口时仍会自动展开。
- 选择“跟随系统隐藏区”后，才会显示“出场顺序”：同时为两面板一起出现；先后为等待系统面板动效结束后再出现收纳面板。切换到手动或悬停模式后，这个选项不显示也不生效；选择会保留。
- 开机启动默认关闭。开启后登录 Windows 自动运行 TrayNest，不负责启动其他软件。
- 可打开收纳面板，或刷新正在运行的软件图标。

## 面板设置

- 展开位置：左侧或上方，分别按底部或左侧对齐；靠近屏幕边缘时自动避让。
- 每行图标数：固定 5–8 列。
- 外观：亚克力、浅色、深色或跟随系统托盘。
- 统一两个面板的材质：让系统隐藏区采用对应外观。同步开启时，“跟随系统托盘”让两个面板采用随系统明暗变化的亚克力。关闭同步或退出后恢复系统原背景；无需安装 Windhawk。
- 移回全部：确认后恢复图标，并清空收纳项目、排序和启动文件设置。

正常退出在设置窗口中，会恢复原图标和系统背景，保留收纳布局。

## 兼容性与问题反馈

当前仅在 Windows 11 25H2 完成实机验证。部分图标拖动时会显示禁止标志，部分图标暂不能收纳。系统内部接口可能随 Windows 更新变化；主面板材质同步也可能与任务栏美化工具冲突。连接失败会提示并保留原设置。详见[兼容性说明](COMPATIBILITY.md)。

在“设置 → 关于 → 诊断与反馈”复制或导出报告。提交时附复现步骤、错误编号（如 TN3001）和事件 ID。报告会过滤用户名、完整路径、图标提示和窗口标题，由你检查后主动提交。

日志位于 `%LOCALAPPDATA%\NestedTray\logs`，程序会限制大小。错误编号见[错误说明](ERROR_CODES.md)。
