# 0.2.0-preview.13

本版修复面板打开后再跳一下对齐的问题，并增加跟随模式的出场顺序设置。

## 连续动画与对齐

原生面板的布局查询移到后台，动画开始前确定显示位置。打开后不再每隔250ms硬挪位置；图标移入移出导致真正的布局变化时，使用平滑移动。

动画帧改由DWM刷新节奏驱动，界面线程在动画期间延后Explorer查询和维护工作。打开与关闭使用不同的曲线和透明度过程，快速关闭再打开保持当前位置和透明度连续。

## 可选出场顺序

“设置 → 常规 → 展开方式”选择“跟随系统隐藏区”后，会显示“出场顺序”：

- **同时**：两个面板一起出现，不等待系统面板的动画。
- **先后**：等待系统面板展开、锚点测量稳定后，再显示收纳面板。

该选项只在跟随模式生效；手动、悬停和拖动靠近入口不使用它。旧配置默认保留“同时”，用户可自行选择。等待期间关闭系统面板或手动取消，不会迟到地弹出收纳面板。

## 宣传页

继续用小图介绍全部功能。按反馈增强图片阴影与边缘，说明改为浅色小字；展开方式只用文字，材质采用有色背景下的亚克力示意，位置图统一基线。主视觉改为暗场聚光与亚克力面板，缩小面板与任务栏间隙；任务栏横贯画面，系统面板中心与 ^ 对齐。

## 验证范围

本机Windows 11 25H2：十组隔离回归；真实桌面的连续轨迹、帧间隔、无二次对齐、出场顺序、取消等待、拖动、菜单和材质检查。帧统计来自测试窗口的实际更新事件，不代表所有设备的显示帧率保证。

Windows 11托盘内部的私有动画参数仍未完整读取。本版使用已核对的公开Popup动画预设和独立的原生面板稳定性检查，不宣称逐像素复刻所有系统版本。其他系统与任务栏美化工具组合仍需兼容性测试。
