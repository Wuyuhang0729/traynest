# 兼容性与测试边界

当前目标是 Windows 11 x64。完整包自带 .NET 10 LTS 运行时；不需要用户额外安装 .NET。

| 场景 | 当前状态 |
|---|---|
| Windows 11 25H2 / 当前实测环境 | 已进行自有测试来源的实机回归 |
| 其他 Windows 11 构建版本 | 有环境检查和未知协议透传保护，尚需真实机器验证 |
| Windows 10、ARM64、非 Windows | 当前版本不列入支持范围 |
| 图标原交互、两来源菜单切换、拖入/拖出 | 自有来源已回归，不能扩大为所有软件均兼容 |
| 配置写入失败 | 验证收纳和移回的回滚、重试及原配置保留 |
| 主进程实际被强制终止 | 在自有测试进程验证独立保护恢复及恢复事件日志 |
| Explorer 实际重启 | 有重连和五分钟三次的限流，未为本轮测试重启用户 Explorer |
| 多屏、其他 DPI、睡眠唤醒、登录启动顺序 | 需要后续设备和长期试用测试 |
| 原生拖动禁止标志、英伟达图标缺少登记 | 仍是已知问题 |
| 面板外观与亚克力 | 四种外观、保存切换和亚克力下入口拖动已在当前机器验证；透明效果和高对比度遵循 Windows 设置 |
| 两种自动展开 | 设置中互斥选择；跟随系统隐藏区、悬停入口、防重复触发与持久化已验证 |
| 主面板材质同步 | preview.12 在本机验证浅色、深色、亚克力、关闭后恢复及自有宿主控制进程异常退出恢复；未覆盖全部 Windows 版本和任务栏美化工具组合 |

未知托盘消息格式保持透传，并在报告中记录形状计数；来源信息不足时不猜测回调。无法确认恢复成功时保留恢复清单。

0.2.0-preview.10 修复已观察到的唤醒后托盘超时退出路径，并通过模拟长时间中断和实际独立窗口超时检查；尚未以整夜待机复测替代上述边界。亚克力轻染色使用 Windows accent policy 兼容接口，不属于稳定的公开 API 合约；不可用时回退到系统材质，显示效果可能随 Windows 更新变化。

公开预览的下一阶段应使用不同 Windows 构建、屏幕布局和常见软件扩大样本。请通过 Issue 提供版本、错误编号、复现步骤及脱敏报告；发布包通过自动回归不等于所有设备已验证。

## TN-012 实测边界（2026-11-10）

本轮 Windows 11 25H2，实际构建 26200.8457，x64；详细配置和证据见 本机定向验收记录。不以注册表遗留的 ProductName 字符串判断 Windows 版本。

- **官方 TranslucentTB 2026.2.0.0**：当前配置及临时全场景 clear/acrylic 分别检查；暂停输入后的展开、反向、原生面板前层、菜单命中、材质开关及恢复通过。仅覆盖记录的组合，没有据此承诺所有配置或启动顺序兼容。同名第三方包 `53454tpxxn.TranslucentTBbytpxxn 1.0.4.0` 未运行，结论不适用该包。
- **RetroBar 1.22.122 x64 便携版**：实际启动后接管通知区，TrayNest 再启动被原生入口保护拒绝；与官方 TranslucentTB 同开也观察到该结果。此为托盘替代程序与当前入口方案冲突，尚不支持同时收纳，不是仅材质问题。新增 TN1005 明确说明先从 RetroBar 菜单正常退出再启动 TrayNest，保留配置；错误提示改进不代表已实现共存。
- **StartAllBack**：未预装；已从官方入口准备并验签安装包，但未确认可独立目录启用且不重载 Explorer 的方式，本轮未安装/启用，未复现其闪烁、穿透或遮挡。不将下载/验签计作兼容实测。
- **层级保护修复**：自有窗口稳定复现任务栏锚点为非置顶时，旧实现将收纳面板一并降为普通窗口而被应用遮住。修复保留自身置顶，仅对置顶原生锚点保持前后顺序；已保留 TN-011 的原生面板前层。尚无证据将这个原因直接归属于上述某款工具。

首轮未暂停输入的透明/亚克力尝试存在位置偏移、提前关闭及材质采样失败；暂停后未复现，原因尚未完全确认，详见验证摘要。尚未覆盖其他美化版本、RetroBar 主题/边缘组合、StartAllBack 与另两款的组合、第三方 TranslucentTB 包，以及本轮真实拖放专项。Explorer 重启故障继续暂缓。
