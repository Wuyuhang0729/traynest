# README 素材来源

当前首页的六张 SVG 均由本项目原创绘制，使用 TrayNest 品牌标识和自有抽象图标，不含私人桌面或个人软件清单。它们用于介绍界面与操作，非实机截图，也不代表第三方兼容认证。

| 文件 | 内容 |
| --- | --- |
| overview-current.svg | 收纳面板、系统隐藏区与任务栏 |
| organize-current.svg | 从系统隐藏区拖入、排序和拖出移回 |
| remember-current.svg | 正常与离线图标混排，点击一个淡色占位尝试启动 |
| opening-modes-current.svg | 联动蓝色方框、独立蓝箭头与保留的系统入口 |
| quick-open-current.svg | 手动、跟随、悬停和 Alt+D，标明默认值与模式条件 |
| material-current.svg | 同一面板内部竖切展示浅色、深色、亚克力，文字另列跟随系统 |

功能卡片尺寸为 880×488；前四项桌面双列，第五项居中，窄屏单列。图中不绘制底部说明条或水印。

SVG 仅含基本图形和文字，无脚本、外部资源或嵌入位图。字体不随素材分发；原创图形按项目 [MIT 许可证](../../LICENSE)提供。

既有历史素材保留，其来源见[原素材说明](../../promo/readme/CREDITS.md)和[图标来源](../../promo/readme/review/SOURCES.md)。其中的第三方名称和图标归各自作者，不表示合作或背书。
