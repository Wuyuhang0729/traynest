# 典型人群案例预览

三个案例都是假设的个人安排，不是行业调查或固定分类规则。按职业和使用场景选择图标，每个案例只显示一个手动选入的收纳面板，软件没有自动分类或多个分类页的新界面。根据后续README优化请求接入正文；远端同步在其余交付完成后进行。

- 程序员：消息与会议留在任务栏；同步、安全、远程连接保留在外层；Docker、PowerToys、ShareX、Everything和Tailscale集中为开发与排障组。显示数量3:6:5。
- 人事部门职员：微信与企业微信保持靠外；QQ、视频会议和安全状态放外层；百度网盘、Snipaste与搜狗输入法设置组成资料、截图、输入组。显示数量2:4:3，接近3:6:5，采用更精简的真实托盘应用组合。
- 游戏影音用户：聊天和游戏平台在任务栏；下载、文件、安全在外层；音乐、播放器、录制和语音集中为影音与语音组。显示数量3:6:5。

中间的入口数包含TrayNest本身。每个案例的三个应用集合不重叠，输入法仅在人事案例的个人筛选中出现。类别标注位于演示界面外，说明选择的结果，不表示产品提供自动识别分类。

当前预览为1080×1820竖版，按“1 最重要／任务栏 → 2 次要重要／系统隐藏区 → 3 个人筛选／TrayNest”从上到下排列。左侧数字与向下箭头明确展开顺序，第3层以蓝色突出；职业应用组合和比例保持不变。

重建竖版排版：运行render-portrait.cjs，直接使用同目录冻结的assets与captures/<case>/panel.png。需要改变个人筛选内容时，可使用capture项目和cases.json中的personal集合重新绘制panel.png；prepare-assets.cjs与render.cjs是工作区历史工具，不属于当前必需的重建入口。完整SVG、独立背景/界面/文字图层和PNG均保留在当前目录。
