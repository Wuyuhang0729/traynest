# 宣传表达

核心文案：**隐藏图标太多？挑一组，单独收好。**

先说明任务栏空间有限，适合保留少量最重要的图标，其余应用常常混在系统隐藏区。TrayNest新增一个手动挑选的收纳层；内外两组都可以按自己的习惯安排，不将新增层限定为“不常用工具”。

使用竖图直接展示任务栏、系统隐藏区、TrayNest三个位置，依次标明最重要、次要重要、个人筛选。应用图标、职业类别、入口和展开顺序比抽象口号更直观。

三种示例：程序员集中开发与排障工具，人事职员集中资料、截图与输入法设置，游戏影音用户集中影音与语音。程序员和游戏影音数量为3:6:5，人事2:4:3；隐藏区计数包括TrayNest入口。它们是个人习惯示意，不是行业调查或兼容性认证，也不代表软件有自动分类、多组标签页或多个面板功能。
