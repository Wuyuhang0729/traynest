# 宣传表达

核心文案：**隐藏图标太多？不常用的，再收一层。**

先交代空间限制：任务栏右下角的位置有限，需要优先留给最重要、最需要及时关注的图标。其余图标进了隐藏区，经常要点的和偶尔才操作的又挤在同一个面板里。再说明TrayNest让用户把不常用的再收进一个可展开面板，给经常用的留下更容易找到的位置。

正文只简要说明背景，把“原来两处位置，新增一层自选收纳”放进使用前后对比图。任务栏、系统隐藏区使用中性色，TrayNest新增部分用蓝色高亮，并标注“自己决定收哪些图标”。其他功能仍由原有功能图说明，不继续堆叠宣传段落。

示例：想及时关注的消息留在任务栏，经常点的工具留在系统隐藏区，偶尔操作的收进TrayNest。软件名称只能作为例子，各人的安排取决于自己的习惯。这是收纳位置的选择；宣传图不应画出自动分类功能，也不把这个使用示例称为Windows官方分类。
